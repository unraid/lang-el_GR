:ud_edit_script_device_settings_plug:
> Επιλέξτε τις επιλογές για αυτή τη συσκευή και το σημείο προσάρτησης.
:end

:ud_edit_script_detach_plug:
> Πατήστε **Αποσύνδεση** για να αποσυνδέσετε τη συσκευή. Η συσκευή θα εμφανίζεται στις Historical Devices και μπορεί να συνδεθεί ξανά από τις ρυθμίσεις συσκευής εκεί.
:end

:ud_edit_script_attach_plug:
> Πατήστε **Σύνδεση** για να συνδέσετε μια συσκευή που έχει αποσυνδεθεί. Θα λειτουργήσει σαν να εγκαταστάθηκε μόλις η συσκευή και θα προσαρτηθεί αυτόματα αν είναι ενεργή η 'Αυτόματη προσάρτηση'. Θα χρειαστεί λίγος χρόνος για να εμφανιστεί η συσκευή στο UD.
:end

:ud_edit_script_abort_plug:
> Πατήστε **Ακύρωση** για να ακυρώσετε το device script.
:end

:ud_disk_name_plug:
> Εισαγάγετε ψευδώνυμο για αυτή τη συσκευή. Είναι το όνομα με το οποίο θέλετε να αναφέρεστε σε αυτόν τον δίσκο. Αφήστε το όνομα κενό για να οριστεί το 'devX'.
>
> **Όνομα:** έως 8 χαρακτήρες, τα κενά μετατρέπονται σε '_', επιτρέπονται ελάχιστοι ειδικοί χαρακτήρες, το όνομα κάνει διάκριση πεζών-κεφαλαίων.
>
> **Σημείωση:** Δεν μπορεί να ξεκινά με "dev". Αυτό είναι δεσμευμένο για τις συσκευές 'devX'.
:end

:ud_edit_script_choose_name_plug:
> Αυτό είναι το αρχείο Script που εκτελείται όταν προσαρτάται η συσκευή. Επιλέξτε το όνομα του αρχείου Script από τη λίστα επιλογής αρχείων ή εισαγάγετε το script που θέλετε.
:end

:ud_edit_user_script_choose_name_plug:
> Αν έχετε εγκατεστημένο το plugin User Scripts, το
Unassigned Devices μπορεί να εμφανίζει την κατάσταση εκτέλεσης του User Script που θα χρησιμοποιεί αυτή τη συσκευή. Το πεδίο ενεργοποιείται μόνο όταν υπάρχει αρχείο Device Script.
:end

:ud_edit_script_run_background_plug:
> Ορίστε **Ναι** για να εκτελείται το Device Script ως εργασία παρασκηνίου. Έτσι το UI του Unassigned Devices δεν "κολλάει" όταν το script εκτελείται από το UI.
:end

:ud_edit_script_buttons_plug:
> Πατήστε **Προεπιλογή** για να γεμίσει το πλαίσιο επεξεργασίας με ένα προεπιλεγμένο Device Script. Πρέπει ακόμα να πατήσετε **Αποθήκευση** για να αποθηκευτεί η αλλαγή.
>
> Πατήστε **Αποθήκευση** για να αποθηκεύσετε το αρχείο Device Script.
>
> Πατήστε **Διαγραφή** για να διαγράψετε το αρχείο Device Script.
>
> Πατήστε **Επαναφορά** για να αναιρέσετε τις αλλαγές σας (πριν την Αποθήκευση).
>
> Πατήστε **Εφαρμογή** για να αποθηκεύσετε τις τρέχουσες αλλαγές.
>
> Πατήστε **Τέλος** για έξοδο από αυτή τη σελίδα.
:end
