Hide Deprecated Applications=Απόκρυψη Παρωχημένων Εφαρμογών
This setting hides deprecated applications from the list of available apps Deprecated apps will still however display within the installed and previous apps sections=Αυτή η ρύθμιση αποκρύπτει τις παρωχημένες εφαρμογές από τη λίστα διαθέσιμων εφαρμογών. Οι παρωχημένες εφαρμογές θα εμφανίζονται ωστόσο στις ενότητες εγκατεστημένων και προηγούμενων εφαρμογών
Hide Incompatible Applications=Απόκρυψη Μη Συμβατών Εφαρμογών
This setting will hide applications that are listed as being incompatible with your version of Unraid=Αυτή η ρύθμιση αποκρύπτει τις εφαρμογές που αναφέρονται ως μη συμβατές με την έκδοση Unraid σας
Allow install of second instance=Να επιτρέπεται εγκατάσταση δεύτερου αντιγράφου
This option enables another button on the cards and popups which will allow you to reinstall an installed application using its default template values This option can be confusing at times, and is only generally used if you wish to install and have an application running twice simultaneously=Αυτή η επιλογή ενεργοποιεί ένα επιπλέον κουμπί στις κάρτες και στα αναδυόμενα, που σας επιτρέπει να εγκαταστήσετε ξανά μια εγκατεστημένη εφαρμογή με τις προεπιλεγμένες τιμές του template της. Η επιλογή μπορεί μερικές φορές να προκαλεί σύγχυση και γενικά χρησιμοποιείται μόνο αν θέλετε να εγκαταστήσετε και να εκτελείτε μια εφαρμογή δύο φορές ταυτόχρονα
Automatically open the sidebar=Αυτόματο άνοιγμα πλαϊνής μπάρας
Allows CA to automatically open the sidebar for more information when hovering over an application's icon=Επιτρέπει στο CA να ανοίγει αυτόματα την πλαϊνή μπάρα με περισσότερες πληροφορίες όταν περνάτε το ποντίκι πάνω από το εικονίδιο μιας εφαρμογής
Allow CA to check for updates to applications=Να επιτρέπεται στο CA ο έλεγχος ενημερώσεων εφαρμογών
This setting enables CA to check for updates to applications Note that Community Applications will always check for updates to itself=Αυτή η ρύθμιση επιτρέπει στο CA να ελέγχει για ενημερώσεις εφαρμογών. Σημειώστε ότι το Community Applications θα ελέγχει πάντα για δικές του ενημερώσεις
Disable Mouse Wheel Page Changes=Απενεργοποίηση Αλλαγής Σελίδας με τη Ροδέλα
This setting disables using left or right on a mouse wheel to change the page=Αυτή η ρύθμιση απενεργοποιεί την αλλαγή σελίδας με κλίση της ροδέλας του ποντικιού αριστερά ή δεξιά
Mouse wheel threshold=Όριο ροδέλας ποντικιού
If you tilt the mouse wheel left or right, the browser returned value will change Set the threshold to the value returned Note that different browsers and operating systems may return different values=Αν γείρετε τη ροδέλα του ποντικιού αριστερά ή δεξιά, η τιμή που επιστρέφει ο browser θα αλλάξει. Ορίστε το όριο στην τιμή που επιστρέφεται. Σημειώστε ότι διαφορετικοί browsers και λειτουργικά συστήματα μπορεί να επιστρέφουν διαφορετικές τιμές
This is a global value for all devices If it causes issues, then disable Mouse Wheel Page Changes=Αυτή είναι γενική τιμή για όλες τις συσκευές. Αν προκαλεί προβλήματα, απενεργοποιήστε την αλλαγή σελίδας με τη ροδέλα
Allow CA to send any emergency notifications=Να επιτρέπεται στο CA η αποστολή επειγουσών ειδοποιήσεων
This setting allows CA to periodically scan your system and alert you to the presence of=Αυτή η ρύθμιση επιτρέπει στο CA να σαρώνει περιοδικά το σύστημά σας και να σας ειδοποιεί για την ύπαρξη
1 Known malware and security vulnerabilities within applications=1. Γνωστού κακόβουλου λογισμικού και ευπαθειών ασφαλείας σε εφαρμογές
2 Critical security vulnerabilities within Unraid OS=2. Κρίσιμων ευπαθειών ασφαλείας στο Unraid OS
3 Any installed applications which may seriously hinder the operation of your server=3. Εγκατεστημένων εφαρμογών που μπορεί να εμποδίσουν σοβαρά τη λειτουργία του διακομιστή σας
Save CA debugging information=Αποθήκευση πληροφοριών αποσφαλμάτωσης CA
Only enable this when advised to from the author of Community Applications=Ενεργοποιήστε το μόνο αν σας το συστήσει ο δημιουργός του Community Applications
Enable developer mode=Ενεργοποίηση λειτουργίας developer
This unlocks some extra features within CA generally only used by developers Not recommended to enable=Ξεκλειδώνει ορισμένες επιπλέον λειτουργίες του CA που συνήθως χρησιμοποιούν μόνο developers. Δεν συνιστάται η ενεργοποίηση
